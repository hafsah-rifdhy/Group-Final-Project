# SpireX Foundation - Internship Portal

A modern, responsive, and interactive **Internship Section** built for the **SpireX Foundation** website platform. This project serves as a showcase for various industry-ready internship tracks, detailing eligibility, learning outcomes, benefits, and an interactive application modal with real-time validation.

Deployment : https://akshithaanagireddy.github.io/Final_project_Frontend_3/

---

## 📌 Project Overview & Role

- **Role:** Member 4 – Internship Section Developer
- **Target Platform:** SpireX Foundation Official Web Portal
- **Tech Stack:** HTML5, CSS3 (Modern Glassmorphism & Custom Properties), Vanilla JavaScript (ES6+)

---

## 🚀 Key Features

### 1. Header & Branding
- High-resolution SpireX Foundation logo integration.
- Responsive top navigation bar with quick links and call-to-action (`Join Now`).

### 2. Internship Track Showcase
- **6 Key Tech Domains:**
  - Full Stack Web Development
  - AI & Machine Learning
  - Data Science & Analytics
  - Cybersecurity & Ethical Hacking
  - UI/UX & Frontend Design
  - Cloud Computing & DevOps
- Detailed card information covering:
  - Mode of delivery (100% Virtual/Remote)
  - Duration (4 Weeks / 8 Weeks)
  - Target Eligibility criteria
  - Key hands-on learning outcomes

### 3. Interactive Filtering
- Dynamic category filter buttons (*All Domains*, *Web & Full Stack*, *AI & Data Science*, *Cybersecurity & Cloud*) allowing instant domain filtering without page reloads.

### 4. Interactive Application System
- Clean, focused **Application Modal Form** with interactive open/close animations.
- Form fields for Candidate Name, Email, Phone/WhatsApp, College Name, Desired Duration, and Portfolio/GitHub links.
- **Client-Side Validation:**
  - Name length check
  - Regex-based Email validation
  - 10-digit Phone number validation
  - Required field validation
- Animated **Toast Notification** confirming successful submission.

### 5. Benefits & Outcomes Grid
- Visual breakdown of program highlights: Verified QR Certificates, Letter of Recommendation (LOR), Real-world Capstone Projects, and Mentor Community Support.
